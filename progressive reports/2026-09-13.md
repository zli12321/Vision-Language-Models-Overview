### Highlights

- **The encoder and the VAE both go.** SenseNova-U1.5 drops the two remaining specialized components of the unified-model stack: it has no vision encoder *and* no image VAE, and it still handles native 4K resolution across understanding, reasoning, and generation. Gemma 4's 12B (last cycle) removed the encoder; SenseNova-U1.5 removes the generation-side VAE too, leaving essentially a single MoT trunk. It is the only genuine open-source base model to arrive in the 33-day window.
- **Driving gets a proper vision-language *foundation*, but on top of Qwen.** Qwen-Drive-1.0 is Alibaba's first attempt to build a pretrained VLM backbone that *is* the driving stack — BEV perception heads (3D detection, occupancy, map segmentation) and planning share one trunk, trained on a staged driving+general vision-language blend. Because it's a continued-pretraining pipeline on the Qwen backbone rather than a from-scratch base model, it is listed under Autonomous Driving (§5, and README §4.3.4).
- **RL infrastructure catches up to the frontier.** Miles v0.1 is the first open reference stack demonstrating fully asynchronous agentic RL post-training on a >700B multimodal MoE (GLM-5.2 744B-A40B) at 4.4 min per step on 64 GB300s. Combined with last cycle's ROSA (VLA serving) and this cycle's on-policy distillation recipes shipped inside SenseNova-U1.5, the MLOps layer for very large multimodal models is now open enough that a lab without hyperscaler infrastructure can attempt it.
- **The frontier's blog wave slowed.** Unlike July's four-flagship blitz (Gemini 3.6 Flash, Kimi K3, GPT-5.6 Sol, Grok 4.5) and early August's Qwen3.8-Max launch, the Aug 11 → Sep 12 window produced no new trillion-scale blog-only launch our radar caught. The frontier signal shifted to *open* unified base models (SenseNova-U1.5) and *domain* foundation models built on existing backbones (Qwen-Drive-1.0, Intern-S2-Preview).

## 7. Key Trends Observed

1. **Era 4 becomes a paradigm, not a claim.** Between DreamX-Phi 1.0 (manipulation), SimWAM (driving), ZimaBlue (cross-embodiment pretraining), G0.5 (one-stream reasoning+action), Puffin-World (native 3D state), SolarWM (open 5B–33B), and Matrix-Game 3.5 (real-time streaming), six groups shipped world-action systems in one 33-day window — each attacking a different failure mode (mechanics, memory, cross-embodiment, low-shot data, real-time inference). The framing has moved from a NVIDIA-Cosmos-3 novelty to something reproducible by many labs.

2. **The unified-model stack keeps shedding components.** Era 3a dropped the vision→LLM bridge; Gemma-4-12B dropped the encoder; **SenseNova-U1.5 now drops the VAE too** — 8B mixture-of-transformers, encoder-free *and* VAE-free, native 4K, understanding + reasoning + generation all in one trunk. The stack is converging on "one transformer, one token stream, one loss."

3. **World models add a reward head.** WorldReward becomes the first VLM-based pairwise preference reward model *for camera-conditioned world models*, beating GPT-5.5 by 3.42/1.45/3.56 points on three dimensions and improving HY-WorldPlay 1.5 in RL post-training. PAWBench formalizes **probabilistic** alignment — comparing repeated rollouts to reference distributions rather than scoring one video. Combined with last cycle's WorldExam ("appearance vs reactivity"), the world-model *evaluation and reward* stack now has three distinct axes and none of the current systems clears them all.

4. **World models spread into computer-use.** WM-R1 trains GUI agents to invoke a world model via RL; WebWorld treats "the browser as a world model" for self-improving web code; GUI-CC benchmarks contextual consistency of GUI world models; Discriminative World Models for Web Agents suggests a *classification* rather than *generation* backbone. World-modeling is no longer just a robotics/simulation concept — it's a design pattern for any embodied *or* GUI agent that has an environment.

5. **VLA scaling shifts from more data to better representations.** Last cycle's data-scaling climb (Hy-Embodied 10k h → Qwen-RobotManip 38k h → LingBot-VLA 2.0 60k h) continues with **ZimaBlue's 120k+ hours** — but the more interesting move is *representation-centric* continued pretraining (VLAct: 82.6% LIBERO-Plus using **20% of trajectories**, beating full-data GR00T-N1.6). Two philosophies now coexist: keep scaling video, or scale the pretraining recipe.

6. **The frontier drops the encoder from perception too.** Qwen-Drive-1.0 packages BEV perception (3D detection, occupancy, map segmentation) and planning inside *one* pretrained-VLM foundation model. Combined with SenseNova-U1.5's encoder-free/VAE-free trunk, the last specialised sensory heads (both driving perception and image encoding) are being pulled into the base model.

7. **Evaluation now asks about the model's own state, not just its outputs.** StateSight explicitly benchmarks *latent spatial-state reconstruction*; ChronoVision (last cycle) attributed the passive-perception gap to a missing reconstructable latent state; "Reason Through the Latent!" trains a recurrence that **strips the visual KV cache before decoding**, forcing latent reasoning. The current mental-model of a VLM's failure has shifted from "wrong answer" to "wrong internal state."

8. **Agentic + real-time evaluation exposes gaps that single-turn QA hid.** VideoGAIA puts **GPT-5.5 and Kimi K3 below 60%** on tool-augmented multi-turn video understanding; OmniAssistBench shows even Gemini-3-Pro at 66.4% on real-time interaction (models fail to wait for target events or track dialogue history); EgoMonth shows the frontier at 71.8% vs 94.2% human on month-long egocentric memory. Every new benchmark that puts a model into a *continuous* rather than *snapshot* setting reopens the gap the offline benchmarks had closed.

9. **RL infrastructure catches up to the frontier.** Miles v0.1 is the first fully open reference stack demonstrating asynchronous agentic RL on a >700B multimodal MoE (GLM-5.2 744B-A40B) at ~4.4 min per step on 64 GB300s. Combined with SenseNova-U1.5's public SFT/RL/on-policy-distillation training code and last cycle's ROSA serving system, the "how do you actually run this thing at production cadence" gap is narrowing in public.

10. **Community re-uploads dominate raw HF signal — don't confuse them with launches.** As in the previous cycle, the top-download "new" multimodal weights this cycle were community quantizations of **Qwen3.8-27B, Nemotron 3 Nano Omni**, and an experimental **DeepSeek-V4-Flash-Vision** upload with no accompanying model card. None represent *original* frontier weight releases in the window. The only three verified original open-weight releases the radar surfaced this cycle are **SenseNova-U1.5-8B-MoT** (09/10, official), **UI-Mate-27B** (08/16, on Qwen3.6-27B), and **AuK / AuK-Flash** (09/08, Tencent Hunyuan). Any survey that ranks by download counts alone will keep mis-dating the frontier.
